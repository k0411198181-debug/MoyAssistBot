# Lonely Women — lonelywomen.ru

Готовый адаптивный одностраничный макет будущего медиа и сообщества женских историй.

## Что работает

- премиальный редакционный дизайн;
- мобильная и компьютерная версии;
- демонстрационные истории в модальных окнах;
- форма истории с локальным сохранением черновика;
- базовые SEO-метатеги;
- один автономный файл `index.html`, который можно перенести на любой статический хостинг.

## Важно

Форма пока не отправляет истории владельцу. Текст хранится только в браузере посетителя. Для запуска приёма историй нужно подключить Telegram-бота, Formspree или собственный backend, а также политику конфиденциальности и согласие на обработку данных.

## Как перенести на отдельный хостинг

1. Скачать `index.html`.
2. Загрузить его в корневой каталог хостинга как `index.html`.
3. Направить DNS домена `lonelywomen.ru` на хостинг.
4. Включить SSL-сертификат.

## GitHub Pages

Для отдельной публикации лучше создать новый публичный репозиторий `lonelywomen-ru`, положить `index.html` в корень и включить **Settings → Pages → Deploy from a branch → main / root**.
